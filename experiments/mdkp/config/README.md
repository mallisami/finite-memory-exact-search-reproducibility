# RQ3 — MDKP work-to-runtime transfer

Primary evidence: 90 fresh cases distributed 30/30/30 over three VMs, with restart, empirical-pW, and direct marginal-work valuation; five counterbalanced timing repetitions per case-policy (1,350 timed rows).

Secondary work evidence: two disjoint unseen blocks (15 and 45 cases), combined with the 90 timing cases only for the reported 150-case executed-node sensitivity.

Mechanism evidence: depth-binned per-node cost, cap-hitting/early-retiring resume diagnostics, 50 matched-trajectory cases, and an implementation-specific allocator-only runtime ceiling estimate. These are explanatory existing-data diagnostics, not additional primary tests.
